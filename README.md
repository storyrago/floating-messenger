# floating-messenger

인스타그램 DM을 데스크탑 앱에서 읽고 답장한다. 텍스트 전용, 개인 사용.
코드네임 `buoy`, 브랜드명 미정.

## 실행

```bash
npm install
npm start
```

처음 켜면 앱 안에서 인스타그램 로그인을 한 번 해야 한다. 세션은 앱에 저장되어 다음부터는 자동이다.

## 지금 상태

- Electron 앱 뼈대, 목록·대화 화면 동작
- 화면 데이터는 아직 임시값. 인스타 응답 필드를 확인한 뒤 실제 데이터로 바꾼다
- 인스타 목록 조회 엔드포인트는 검증됨. 전송은 미검증

## 하지 않는 것

모르는 사람에게 배포하지 않는다. 앱 안 웹뷰에 비밀번호를 입력하는 구조라 사용자가 진위를
확인할 수 없고, 비공식 엔드포인트 사용의 계정 위험이 사용자에게 간다. 배포하려면 공식
Instagram 메시징 API를 쓰는 별도 프로젝트가 필요하다 (ADR-011 메모).
