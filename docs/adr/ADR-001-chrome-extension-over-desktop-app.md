# ADR-001. 데스크탑 앱 대신 Chrome 확장프로그램으로 만든다

- 상태: 채택
- 날짜: 2026-09-07

## 맥락
처음 목표는 "인스타그램 DM용 데스크탑 앱"이었다. 요구는 (1) 인증이 즉시 될 것 (2) 웹보다 체감이 빠를 것 (3) 텍스트만 (4) 개인 사용.
개인 계정 DM에 공식 API가 없어 선택지는 웹 세션 재사용 또는 모바일 비공개 API 모방이다.

## 결정
Chrome 확장프로그램(MV3)으로 만든다. 데스크탑 앱은 만들지 않는다.

## 근거
- 인증: 브라우저에 이미 로그인된 세션을 그대로 쓰므로 인증 작업이 0이다. 2FA·의심 로그인 챌린지는 인스타 화면이 처리한다.
- 정지 위험: 트래픽이 웹 클라이언트와 동일해 계정 정지 위험이 웹 사용 수준이다.
- 실시간: 인스타 페이지가 열어 둔 WebSocket을 신호로 쓸 수 있어 프로토콜을 구현하지 않아도 된다.
- 속도: 체감 속도는 가벼운 UI와 백그라운드 스로틀링 회피에서 나오며, 확장의 별도 UI(iframe/창)로 충분히 달성 가능하다.
- 개발 속도: 프로토타입이 며칠 단위.

## 결과
- 장점: 인증·실시간·세션 관리를 만들지 않는다. 유지보수 대상이 UI와 중계로 줄어든다.
- 단점: 무거운 인스타 페이지(엔진 탭)가 뒤에서 계속 실행된다. 브라우저 밖 독립 창·OS 알림은 제한적이다(팝업 창·notifications로 일부 보완).
- 필요해지면 같은 콘텐츠 스크립트를 Electron/Tauri 웹뷰 안에 넣어 앱으로 감쌀 수 있다(구조 재사용).

## 검토한 대안
- Electron/Tauri + 모바일 비공개 API: 로그인 챌린지 잦음, 정지 위험 큼, 프로토콜 유지보수 부담. 기각.
- Electron/Tauri + 웹뷰 임베드: 확장의 장점을 대부분 유지하지만 개발·배포 비용이 더 크다. 후속 옵션으로 보류.
- 공식 Instagram Messaging API: 비즈니스 계정·페이지 연결·앱 심사 필요, 개인 계정 불가. 기각.
